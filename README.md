# getkurafuto.app

The website of [Kurafuto](https://getkurafuto.app), the iPhone app for self-hosted Crafty Controller 4 panels: landing page, privacy policy (English and German) and legal notice (Impressum).

Static HTML and one stylesheet in `site/`, deployed to GitHub Pages on every push to `main`. The app itself is closed source.
